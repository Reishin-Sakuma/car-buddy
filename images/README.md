# CarBuddy 画像フォルダー

このフォルダーにPNG形式のキャラクター画像を配置してください。

## 必要な画像ファイル

以下のファイル名で画像を用意してください：

### character_normal.png
- **用途**: 通常状態のキャラクター画像
- **推奨サイズ**: 180x180ピクセル
- **フォーマット**: PNG（透明度対応）
- **表示条件**: 温度が32°C未満の時

### character_hot.png
- **用途**: 高温時のキャラクター画像
- **推奨サイズ**: 180x180ピクセル
- **フォーマット**: PNG（透明度対応）
- **表示条件**: 温度が32°C以上の時

### character_wink.png（オプション）
- **用途**: 特別なイベント時のキャラクター画像
- **推奨サイズ**: 180x180ピクセル
- **フォーマット**: PNG（透明度対応）
- **表示条件**: 将来的な機能拡張用

## 画像仕様

- **ファイル形式**: PNG
- **推奨サイズ**: 180x180ピクセル
- **背景**: 透明または単色
- **色深度**: 24bit/32bit
- **圧縮**: 標準PNG圧縮

## 注意事項

- ファイル名は大文字小文字を区別します
- 画像が見つからない場合、該当する表示はスキップされます
- 画像サイズが異なる場合、自動的に180x180にリサイズされます
